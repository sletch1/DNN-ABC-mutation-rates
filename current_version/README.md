# DNN-ABC: neural surrogates for approximate Bayesian computation of mutation rates

Code, data and manuscript for *Deep Neural Network Surrogates for Approximate Bayesian Computation: A Simulation Study for
Mutation-Rate Estimation in Markov Branching Processes* (Letchumanan, Zhu, Wu).

The paper asks whether a neural network can replace the Gaussian process inside **GPS-ABC**, the sampler of
Lu, Zhu & Wu (2023), *Estimating mutation rates in a Markov branching process using approximate Bayesian computation*,
J. Theoretical Biology 565:111467, and when that helps. It has two studies:

| | Model | Folder |
|---|---|---|
| **Study I** | one parameter, constant mutation probability `p` | [`1D/`](1D/README.md) |
| **Study II** | two-stage mutation rate with differential growth, `(p1, p2, τ, δ)`: the original paper's Simulation Study 2, in its own regime | [`4D/`](4D/README.md) |

Study II is the main study. It compares **GPS-ABC** (the original authors' MATLAB code, run on our data), **DNN-ABC** (the same
sampler with a zero-aware neural surrogate, and a control trained on only the original design size) and **NPE** (amortized neural
posterior estimation, trained on the same simulations), with simulation-based calibration over prior draws. The data generator is
checked against the training sets the original authors released (`4D/tests/validate_vs_published.py`).

## Layout

```
manuscript.tex / .pdf      the paper (figures/ and tables/ are generated by the code)
1D/                        Study I: simulator, surrogate, ABC sampler, tables, figures
4D/                        Study II: simulator, data generation, surrogate + architecture search,
                           DNN-ABC, NPE, calibration, MATLAB GPS-ABC wrapper, analysis
Original_Paper_Code/       the original authors' MATLAB reference implementation (unmodified)
RCode/                     R simulators and the Study I ground-truth generators
tables/, figures/          generated by 4D/analysis/ and pulled into the manuscript
paper_code_discrepancy.md  where the published paper and the released code disagree, and which we follow
```

**Rule used throughout:** where the original paper and the original code disagree, we follow the paper
(`paper_code_discrepancy.md`).

## Requirements

Python 3.9+ with `requirements.txt` (`numpy`, `pandas`, `scipy`, `matplotlib`, `scikit-learn`, `torch`, `sbi`); no GPU.
Running the original GPS-ABC sampler (Study II baseline) additionally needs MATLAB with the Statistics and
Parallel Computing toolboxes. Heavy steps (data generation, the architecture search, GPS-ABC) are written for a
multi-core Linux server; see `4D/server/`.

## Reproducing

Study I: see [`1D/HOW_TO_RUN.md`](1D/HOW_TO_RUN.md). Study II: see [`4D/README.md`](4D/README.md); every table and figure of
the paper is regenerated from the result files by `4D/analysis/`, with no hand-copied numbers.

  single function (`mut_bMBP_rev.m`) used for the Study II GPS-ABC runs lives in `4D/gps_abc/patched/`, with the reason
  documented at the top of the file.
